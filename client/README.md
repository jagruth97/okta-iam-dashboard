# Okta IAM Dashboard — Client Application

This is the React frontend for the [Okta IAM Dashboard](../README.md).

## Quick Start

```bash
npm install
cp .env.example .env.local   # configure Okta issuer and client ID
npm run dev
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start Vite dev server (http://localhost:5173) |
| `npm run build` | Production build |
| `npm run lint` | Run Oxlint |
| `npm run preview` | Preview production build |

See the [root README](../README.md) for Okta setup, RBAC configuration, and troubleshooting.
